🤖 Gerar Sensibilidade

Tudo relacionado à criação e regeneração fica nesta área.

ℹ️ Para que serve? Use esta área quando quiser criar uma nova sensibilidade. As opções disponíveis no gerador existente continuam sendo usadas; esta página funciona como a área organizada de acesso.

⚙️ Gerador principal

Abra o gerador original da versão 2.0 para escolher seu aparelho e demais parâmetros.

Como usar
  1. Selecione o modelo do aparelho.
  2. Confira ou ajuste DPI, FPS e Hz quando essas opções estiverem disponíveis.
  3. Escolha seu estilo e demais parâmetros.
  4. Gere a configuração.
  5. Teste no jogo e use a Calibração para registrar como ficou.

📱 Aparelhos

Banco, busca e informações dos celulares.

ℹ️ Para que serve? Encontre seu modelo exato ou um modelo disponível no banco e use os dados dele para ajudar na configuração.

🔎 Banco de aparelhos

A área original de aparelhos continua preservada.

Ações

🎯 Calibração

Ajuste a configuração depois de testar.

ℹ️ Para que serve? A calibração registra sua avaliação da sensibilidade gerada e aplica uma sugestão de ajuste. Ela não substitui seu teste no jogo.

⚡ Muito rápida

Use quando a sensibilidade estiver passando demais do ponto para você.

🐢 Muito lenta

Use quando estiver difícil movimentar a mira com a velocidade desejada.

✅ Boa

Registre quando a configuração estiver adequada ao seu teste.

➖ Mais ou menos

Registre quando precisar de um pequeno ajuste.

🔫 Configuração por arma

Ajustes separados por categoria.

ℹ️ Para que serve? Escolha o tipo de arma que você quer priorizar. O sistema usa a categoria para propor um ajuste sobre a configuração atual.

⚡ SMG

Perfil para armas de combate de curta/média distância.

💥 Escopeta

Perfil para priorizar movimentos rápidos em curta distância.

🎯 Rifle / AR

Perfil para uso geral em curta e média distância.

🔭 Sniper / AWM

Perfil voltado para controle em distâncias maiores.

💾 Configurações Salvas

Um lugar separado para guardar e administrar suas configurações.

ℹ️ Para que serve? Use esta área para não precisar refazer uma configuração que você já criou. Recursos disponíveis dependem do armazenamento local/Firebase já existente no arquivo.

📊 Estatísticas

Acompanhe o uso do aplicativo e seu progresso.

ℹ️ Para que serve? Esta área reúne números e progresso que já estejam disponíveis no sistema, sem misturar estatísticas com o gerador.
